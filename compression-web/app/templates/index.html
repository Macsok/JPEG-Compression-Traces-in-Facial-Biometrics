How to read the results

JFIF indicates features typical of JPEG compression, while PPM indicates features typical of uncompressed images in the training set. This is a prediction from pixels, not a reading of the file format.

JPEG quality is a model estimate, not a camera setting or a visual rating. For PPM predictions, quality is indicative only. Confidence applies to the PPM / JFIF classification and does not guarantee accuracy.
